## API Endpoints Available

### Get all rooms
```
GET /api/availability?hostelId=<id>&checkIn=YYYY-MM-DD&checkOut=YYYY-MM-DD
```

### Get rooms by floor
```
GET /api/rooms?floor=1&hostelId=<id>
```

### Room management
```
GET /api/admin/rooms
PATCH /api/admin/rooms/<id>
```
